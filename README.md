# BMI Calculator

A simple BMI (Body Mass Index) Calculator built with React, Vite, and Tailwind CSS.

This project is part of my React.js learning journey, where I am practising React fundamentals through small hands-on projects.

## Features

- Calculate BMI using weight and height
- Display BMI results
- Categorize BMI results
- Input validation
- Reset functionality
- Responsive user interface

## Tech Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/bmi-calculator-react.git
```

### 2. Navigate to the project directory

```bash
cd bmi-calculator-react
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```
